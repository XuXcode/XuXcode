## 🚀 Featured Projects

### 🔍 [dsh-loghud](https://github.com/XuXCode/dsh-loghud)

**Real-time Spring Boot error HUD with opt-in AI diagnosis for DeepSeek Harness.**

A developer tool designed to make Spring Boot debugging more intuitive by displaying runtime errors directly inside DeepSeek Harness.

* ⚡ Real-time Spring Boot log monitoring
* 🔍 Automatic error detection and stack trace display
* 🤖 Optional AI-powered error diagnosis
* 🧑‍💻 Designed for both beginners and experienced developers
* 🎯 AI analysis is opt-in instead of interrupting the normal debugging workflow

**Tech Stack:** `TypeScript` · `DeepSeek Harness` · `Log Monitoring` · `AI`

### 🤖 [career-planning-agent](https://github.com/XuXCode/career-planning-agent)

**AI-powered career planning assistant built with Spring Boot and DeepSeek.**

An AI application designed to help university students better understand their career direction through resume analysis and job matching.

* 📄 Resume analysis
* 🎯 Internship and job matching
* 🧠 AI-powered career suggestions
* 📊 Career development reports
* 💬 LLM-powered intelligent interaction

**Tech Stack:** `Java` · `Spring Boot` · `DeepSeek` · `LLM`
